# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/iSmartyPRO/isms-gw-android/security/advisories/new)
or through the contact form at [www.ismarty.pro](https://www.ismarty.pro).

Include the app version, device / Android version, steps to reproduce and the impact.
We aim to acknowledge reports within 72 hours and to ship a fix as soon as possible.

## Scope

In scope: the Android app, the embedded HTTP server and web panel, the REST API, webhooks,
the Telegram bot and the persistent WebSocket link.
Out of scope: vulnerabilities that require root access or a compromised device, and issues in Android itself.
